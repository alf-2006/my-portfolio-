# إدارة عرض المشاريع من GitHub

بيانات البطاقات تأتي من مستودعات `alf-2006` العامة الأصلية، وليست من قاعدة بيانات منفصلة. نافذة المشروع تجلب README واللغات عند فتحها، وتحاول استخراج صور العرض وروابط الفيديو المتاحة. الصور والشارات التقنية والشعارات ليست شيئًا واحدًا؛ شارات البناء والاعتماديات لا تُعامل كصور للمشروع.

## إضافة صور أو فيديو لمشروع

عدّل ملف [`content/project-showcases.json`](https://github.com/alf-2006/my-portfolio-/blob/main/content/project-showcases.json) على GitHub. كل مفتاح داخل `projects` هو اسم المستودع بالضبط. يوجد مثال فعلي لمشروع `elahmed-retail-suite-main` بصورتَي الكمبيوتر والموبايل.

يمكنك رفع الوسائط إلى مستودع المشروع نفسه أو إلى `public/projects/` في مستودع البورتفوليو، واستخدام رابط HTTPS مباشر. رابط صورة محفوظة في هذا البورتفوليو يكون على الشكل التالي:

```text
https://raw.githubusercontent.com/alf-2006/my-portfolio-/main/public/projects/NAME.webp
```

الحقول الاختيارية للمشروع:

| الحقل | المحتوى |
| --- | --- |
| `title` | اسم العرض |
| `summary` | وصف مختصر حقيقي للمشروع |
| `highlights` | قائمة بأهم الوظائف الفعلية |
| `media` | قائمة الصور والفيديوهات، بحد أقصى 12 عنصرًا |

يمكن كتابة النص مباشرة، أو توفير اللغتين في كائن مثل `{"en":"Desktop interface","ar":"واجهة الكمبيوتر"}`. عند غياب إحدى اللغتين تُستخدم الأخرى، ولا تُنشأ ترجمة أو معلومات تلقائية.

## أنواع الوسائط

**صورة:** استخدم `type: "image"`، و`src` لرابط الصورة المباشر، و`alt` لوصف الصورة لقرّاء الشاشة. `caption` تعليق اختياري يظهر تحتها.

**فيديو مباشر:** استخدم `type: "video"` مع رابط MP4 أو WebM مباشر. `poster` اختياري لصورة الغلاف. يمكن إضافة ترجمات عبر `captions`، مثل قائمة بعناصر تتضمن `src` لرابط VTT و`language` مثل `ar` و`label` مثل `العربية`. يجب أن يسمح مضيف الفيديو/ملف الترجمة بعرضهما في المتصفح.

**YouTube:** استخدم `type: "youtube"` مع رابط الفيديو. يحوّله مصدر البيانات إلى رابط تضمين YouTube محدّد وآمن. لا يُحمّل مشغّل YouTube إلا بعد ضغط الزائر على زر التشغيل. الفيديو يجب أن يسمح بالتضمين؛ إن كان خاصًا أو يمنع التضمين فقد لا يعمل داخل النافذة، ويظل رابط الأصل متاحًا.

لا ترفع فيديو كبيرًا إلى GitHub إذا كان يتجاوز حدوده أو يثقل المستودع؛ استخدم فيديو YouTube عامًا/غير مدرج أو رابط فيديو مباشر من مضيف مناسب.

## ما يظهر عند عدم وجود محتوى

المشروع بدون صور أو فيديو يعرض تفاصيله وروابطه مع توضيح أن الوسائط لم تُضف بعد. إذا لم يتوفر وصف حقيقي في GitHub أو في ملف العرض فلن تُختلق تفاصيل. نصوص القوالب مثل `REPLACE_WITH_PROJECT_ID` لا تُستخدم كوصف للمشروع. يستطيع الزائر فتح README الأصلي على GitHub.

## التحديثات

المحتوى العام يُخزّن مؤقتًا لتقليل طلبات GitHub ويُجدّد دوريًا؛ قد تتأخر رؤية تعديل البيانات إلى ما يقارب ساعة أو إلى طلب التجديد التالي. تعديل الملف المتتبّع في مستودع البورتفوليو يطلق أيضًا النشر المعتاد على Vercel. لا تحتاج إلى تعديل مكوّنات الواجهة لإضافة وسائط أو معلومات لمشروع.

## العرض والإتاحة

تدعم النافذة إغلاق Escape وزر الإغلاق، وحصر التركيز داخلها وإعادته إلى زر المشروع بعد الإغلاق. تتوقف حركة الخلفية أثناء فتحها، ويظل محتواها قابلًا للتمرير. على الموبايل تُعرض بملء الشاشة، وتراعي تفضيل تقليل الحركة. روابط GitHub والموقع المباشر والوسائط الأصلية تفتح في تبويب جديد.
