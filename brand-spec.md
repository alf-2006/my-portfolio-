# ALF Portfolio Brand Spec

- **Identity asset:** `public/brand/alf-logo-800.webp` — reuse the existing ALF logo; do not substitute text, create a project logo, or redraw it.
- **Palette:** use the existing light/dark theme tokens in `src/app/globals.css` (`--blue`, `--paper`, `--surface`, `--ink`, `--muted`, and `--line`).
- **Typography:** retain the current site font stacks and heading scale.
- **Shape and depth:** retain the site's compact 8px corner language, hairline borders, and existing card shadows.
- **Motion:** use short, state-driven transitions; honor the existing reduced-motion behavior.
- **Project data:** obtain repository metadata from the public GitHub API for `alf-2006`; do not duplicate or invent project descriptions in the locale dictionaries.
